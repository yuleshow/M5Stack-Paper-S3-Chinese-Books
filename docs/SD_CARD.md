# SD Card File Structure

This document describes all files and directories the M5Stack Paper S3 firmware expects on the SD card.

> The SD card must be formatted as **FAT32**.
>
> All SD card files are kept in the `sd_card/` folder of this repository. Copy the contents of `sd_card/` to the root of your SD card.

## Directory Tree

```
SD Card Root/
├── config.ini                ← WiFi, timezone, weather, BLE unlock
├── mottos.txt                ← Sleep-screen mottos, one per line
├── cangjie5.bin              ← Cangjie input method dictionary
├── shopping_list.csv         ← Shopping list
├── todo_list.csv             ← Todo list
├── calendar_events.csv       ← Custom calendar events
├── books/
│   ├── *.txt                 ← UTF-8 plain text books
│   └── *.epub                ← EPUB e-books
├── fonts/
│   ├── *.ttf                 ← TrueType fonts
│   ├── *.ttc                 ← TrueType Collection fonts
│   └── *.bin                 ← Pre-rendered binary fonts
├── wallpapers/
│   ├── *.jpg / *.jpeg        ← JPEG wallpaper images
│   ├── *.png                 ← PNG wallpaper images
│   └── *.bmp                 ← BMP wallpaper images
├── icons/
│   └── icon1.png – icon8.png ← Custom dashboard icons
├── dict/
│   └── en-zh.txt              ← English-Chinese dictionary (for long-press lookup)
└── fortune_slips/
    ├── kuanyin.bin            ← 觀音靈籖 (Guanyin fortune slips)
    └── sensoji.bin            ← 淺草寺靈籖 (Sensoji fortune slips)
```

## Configuration Files

### `config.ini` (recommended)

Main configuration file. Controls WiFi, timezone, weather, and BLE unlock.

```ini
[wifi]
ssid=YOUR_WIFI_SSID
password=YOUR_WIFI_PASSWORD

[time]
timezone=PST8PDT
gmtoffset=-28800

[weather]
apikey=YOUR_OPENWEATHERMAP_API_KEY
city=Pasadena,CA,US
units=metric

[unlock]
enabled=false
device_name=M5Paper-BLE
```

See `assets/config.ini.example` for a template.

### `mottos.txt` (optional)

One motto per line (UTF-8). Displayed on the wallpaper / sleep screen. If not present, a built-in default motto is used.

### `cangjie5.bin` (optional)

Binary dictionary for the Cangjie input method. Generated from `data/cangjie5.dict.yaml` using `scripts/convert_cangjie.py`.

## Data Files

### `shopping_list.csv` (optional, read/write)

Shopping list in `group|item` format, one entry per line:

```csv
水果|蘋果
水果|香蕉
飲料|牛奶
```

The firmware auto-creates `shopping_checked.txt` to persist checked-item state.

### `todo_list.csv` (optional, read/write)

Todo list in `date,task` format:

```csv
2026-03-07,買菜
2026-03-08,寫報告
```

The firmware auto-creates `todo_checked.txt` to persist checked-item state.

### `calendar_events.csv` (optional)

Custom calendar events displayed on the calendar screen.

## Books — `/books/`

| File Type | Description |
|-----------|-------------|
| `*.txt`   | UTF-8 plain text books |
| `*.epub`  | EPUB e-books |

- Maximum **100** books displayed in the list.
- The firmware auto-creates sidecar files alongside each book:
  - `<name>.txt.pos` / `<name>.epub.pos` — reading position
  - `<name>.txt.bm` / `<name>.epub.bm` — bookmarks (up to 5)

## Fonts — `/fonts/`

| File Type | Description |
|-----------|-------------|
| `*.ttf`   | TrueType font |
| `*.ttc`   | TrueType Collection (multiple faces) |
| `*.bin`   | Pre-rendered binary font (generated by `scripts/convert_ttf_to_bin.py`) |

- Maximum **100** font files scanned.

### System Font

The firmware looks for a system font in this priority order:

1. **`GenYoMinTW-Regular.ttf`** — preferred system font (源樣明體). If found, it is loaded automatically.
2. Any other `.ttf` or `.ttc` file — used as a fallback if GenYoMinTW is not present.
3. `.bin` font — last resort, with preference for `MingLiU`-based files.

The system font is used for all UI text: menus, labels, book reader, dashboard, calendar, etc.

### Motto Font (Kai)

The motto / 醒世格言 feature looks for:

- **`TW-Kai-98_1.ttf`** — a traditional Kai (楷書) font used for vertical motto text rendering on the wallpaper and sleep screen.

If not found, the firmware falls back to the built-in font. For the best visual experience with mottos, place this file in `/fonts/`.

### Silver Font

Silver is an alternative system font with a pixel-art aesthetic. To use it:

- Place **`Silver.ttf`** in `/fonts/`.
- The firmware auto-detects any font whose filename contains "Silver" and switches to Silver mode.
- Pre-rendered `.bin` files should be named **`Silver_<size>pt.bin`** (e.g. `Silver_36pt.bin`).

Silver glyphs are rendered **~38% larger** than their nominal point size so they match the visual weight of GenYoMinTW at the same setting. The firmware handles this scaling automatically — no manual adjustment is needed.

You can switch between GenYoMinTW and Silver from the font selection menu on the device.

## Wallpapers — `/wallpapers/`

| File Type | Description |
|-----------|-------------|
| `*.jpg` / `*.jpeg` | JPEG image |
| `*.png` | PNG image |
| `*.bmp` | BMP image |

- Maximum **30** wallpaper files.
- Recommended resolution: **540 × 960** pixels (matches the e-ink display).
- Maximum file size: **2 MB** per image.

| File | Icon Position |
|------|---------------|
| `icon1.png` | Top-left (閱讀) |
| `icon2.png` | Top-right (字型) |
| `icon3.png` | Row 2 left (待辦) |

Icons should be **PNG** format. If a custom icon is not found, the built-in embedded icon is used.

## Dictionary — `/dict/`

English-Chinese dictionary for the long-press word lookup feature in English reading mode.

| File | Description |
|------|-------------|
| `en-zh.txt` | Tab-separated English-Chinese dictionary, sorted alphabetically |

Long-press any word while reading an English book to see its Chinese translation in a popup.

### Generating the dictionary

The dictionary is generated from [ECDICT](https://github.com/skywind3000/ECDICT) (MIT license, ~770K entries):

1. Download `ecdict-sqlite-28.zip` from the [ECDICT releases page](https://github.com/skywind3000/ECDICT/releases)
2. Extract `stardict.db`
3. Run the conversion script:

```bash
python3 scripts/convert_ecdict.py path/to/stardict.db
```

This generates `sd_card/dict/en-zh.txt` (~2.5 MB, top 50,000 words by frequency). Copy the `dict/` folder to your SD card.

## Fortune Slips — `/fortune_slips/`

Binary pack files containing pre-resized (540 × 960) JPEG fortune slip images.

Fortune slip images sourced from [www.chance.org.tw](https://www.chance.org.tw).

| File | Description | Generated By |
|------|-------------|-------------|
| `kuanyin.bin` | 觀音靈籖 — 100 Guanyin fortune slips | `scripts/convert_fortune_slips.py` |
| `sensoji.bin` | 淺草寺靈籖 — 100 Sensoji temple fortune slips | `scripts/convert_fortune_slips.py` |

Source images are in `assets/Fortune_Slips/`. Run the converter to generate the `.bin` files:

```bash
python3 scripts/convert_fortune_slips.py
```

Then copy from `data/` to the SD card's `/fortune_slips/` directory.

## Auto-Created Files

These files are created and managed by the firmware automatically. Do not edit them manually.

| File | Purpose |
|------|---------|
| `shopping_checked.txt` | Checked items in shopping list |
| `todo_checked.txt` | Checked items in todo list |
| `books/<name>.pos` | Reading position for each book |
| `books/<name>.bm` | Bookmarks for each book |

---

## Notes

- The firmware runs `cleanupMacOSFiles()` on boot, which removes `.DS_Store`, `._*` (AppleDouble), `Thumbs.db`, and `desktop.ini` files from the SD card.
- Files can also be managed via the built-in **web file manager** when WiFi is connected (accessible through the setup screen).
