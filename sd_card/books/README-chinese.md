# 書籍

![內容](https://img.shields.io/badge/類型-內容-purple)
![格式](https://img.shields.io/badge/格式-TXT_/_EPUB-blue)

中文電子書閱讀器的電子書檔案。將 UTF-8 編碼的文字檔（`.txt`）和 EPUB 檔案（`.epub`）放置於此。

## 支援格式

- **TXT** — 純文字，UTF-8 編碼。以直排中文排版渲染（由右至左分欄）。
- **EPUB** — 標準 EPUB 格式。HTML 內容被擷取並渲染為純文字。

## 自動產生的附屬檔案

閱讀器會自動在每本書旁建立附屬檔案：

| 副檔名 | 用途 |
|--------|------|
| `.pos` | 儲存的閱讀進度（位元組偏移量）。閱讀書籍時自動建立。 |
| `.bm` | 書籤檔案（每本書最多 5 個）。新增書籤時建立。 |

這些檔案因屬於使用者自訂而已加入 gitignore。
