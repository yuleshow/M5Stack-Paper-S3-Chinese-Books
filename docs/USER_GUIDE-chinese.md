## 硬體需求

| 元件 | 詳情 |
|------|------|
| **裝置** | M5Stack Paper S3 |
| **處理器** | ESP32-S3 @ 240 MHz |
| **螢幕** | 540×960 電子墨水，4 位元灰階（16 色階） |
| **觸控** | GT911 電容式觸控 |
| **記憶體** | OPI PSRAM |
| **儲存** | MicroSD 卡插槽 |
| **連線** | USB-C、WiFi 2.4 GHz |

**您需要準備：**
- 一張 microSD 卡（FAT32 格式，建議 32 GB 以下）
- 一條 USB-C 傳輸線（用於燒錄和充電）
- 安裝了 [PlatformIO](https://platformio.org/) 的電腦（用於編譯韌體）

## SD 卡設定

將 microSD 卡格式化為 **FAT32**，然後建立以下資料夾結構：

```
SD 卡根目錄/
├── config.ini          ← WiFi、時區、天氣 API 設定
├── mottos.txt          ← 每行一句格言（選用）
├── shopping_list.csv   ← 購物清單資料（選用）
├── todo_list.csv       ← 待辦事項資料（選用）
├── cangjie5.bin        ← 倉頡輸入法字典（選用）
├── books/
│   ├── 三國演義.txt     ← UTF-8 編碼文字檔
│   ├── MyBook.epub     ← EPUB 電子書
│   └── ...
├── fonts/
│   ├── GenYoMinTW-Regular.ttf  ← 建議使用的系統字型
│   └── ...              ← 其他 TTF/TTC/BIN 字型
├── wallpapers/
│   ├── scenery.jpg      ← JPG/PNG/BMP 圖片
│   └── ...
└── icons/
    ├── icon1.png        ← 自訂主畫面圖標（選用）
    ├── icon2.png
    └── ... (最多 icon8.png)
```

### 設定檔

在 SD 卡根目錄建立 `config.ini`：

```ini
[wifi]
ssid=你的WiFi名稱
password=你的WiFi密碼

[time]
timezone=CST-8
gmtoffset=28800

[weather]
apikey=你的OPENWEATHERMAP_API金鑰
city=Taipei,TW
units=metric
```

**時區預設值**（使用 `timezone` 和 `gmtoffset` 參數）：

| 地點 | timezone | gmtoffset |
|------|----------|-----------|
| UTC+0 | `UTC0` | `0` |
| 北京 / 台北 +8 | `CST-8` | `28800` |
| 東京 +9 | `JST-9` | `32400` |
| 美西 -8/-7 | `PST8PDT` | `-28800` |
| 美東 -5/-4 | `EST5EDT` | `-18000` |
| 英國 +0/+1 | `GMT0BST` | `0` |
| 雪梨 +10/+11 | `AEST-10AEDT` | `36000` |

**天氣 API 金鑰：** 至 [openweathermap.org/api](https://openweathermap.org/api) 取得免費金鑰。免費方案支援目前天氣和預報。

### 書籍

- **TXT 檔案** 必須為 UTF-8 編碼，放置於 `/books/`。
- **EPUB 檔案** 支援內建解壓縮，標題自動從中繼資料擷取。
- 最多 20 本書。

### 字型

將 TTF、TTC 或預渲染 BIN 字型放入 `/fonts/`。裝置開機時會掃描此資料夾。

- **系統字型：** [源樣明體 GenYoMinTW-Regular.ttf](https://github.com/ButTaiwan/genyo-font/releases) — 繁體中文明體字型
- **格言字型：** [全字庫正楷體 TW-Kai-98_1.ttf](https://data.gov.tw/dataset/5961) — 來自 CNS11643 的繁體中文楷體字型（OFL-1.1 授權）。直接下載：[Fonts_Kai.zip](https://www.cns11643.gov.tw/opendata/Fonts_Kai.zip)
- 可在閱讀畫面透過「字型」按鈕切換字型。
- 最多支援 100 個字型檔案。

### 桌布

將 JPG、PNG 或 BMP 圖片放入 `/wallpapers/`。

- **建議解析度：** 540×960 像素（與螢幕相同）
- **JPG 建議：** 匯出為基線格式（非漸進式），品質 85–95
- 每張最大 2 MB，最多 30 個檔案

## 燒錄韌體

### 方式 A：預編譯韌體

從 [Releases](https://github.com/yuleshow/M5Stack-Paper-S3-Chinese-Books/releases) 頁面下載韌體。提供兩種版本：

#### 16 MB 合併韌體（建議）

包含 bootloader、分區表及應用程式 — 適用於全新/空白裝置或完整重新燒錄：

```bash
pip install esptool  # 如尚未安裝
esptool.py --chip esp32s3 --port /dev/cu.usbmodem* write_flash 0x0 M5Paper-S3-Chinese-Books-*-merged.bin
```

#### 8 MB 純應用程式韌體

僅包含應用程式韌體。適用於已有有效 bootloader 和分區表的裝置（例如之前曾執行 `pio run -t upload`）：

```bash
esptool.py --chip esp32s3 --port /dev/cu.usbmodem* write_flash 0x10000 M5Paper-S3-Chinese-Books-*-app-only.bin
```

> **連接埠備註：** macOS 通常為 `/dev/cu.usbmodem*`，Linux 為 `/dev/ttyACM0`，Windows 為 `COM3`（請查看裝置管理員）。

### 方式 B：從原始碼編譯

1. 安裝 [PlatformIO](https://platformio.org/)（VS Code 擴充功能或命令列工具）
2. 複製儲存庫：
   ```bash
   git clone https://github.com/yuleshow/M5Stack-Paper-S3-Chinese-Books.git
   ```
3. 透過 USB-C 連接 M5Stack Paper S3
4. 編譯並上傳：
   ```bash
   cd M5Stack-Paper-S3-Chinese-Books
   pio run -t upload
   ```

相依套件（`M5Unified`、`OpenFontRender`）由 PlatformIO 自動安裝。

## 首次開機

1. 將準備好的 SD 卡插入 M5Stack Paper S3
2. 連接 USB-C 或按下電源按鈕
3. 出現**歡迎畫面**顯示封面圖片
4. **點擊螢幕任意處**進入主畫面

如果 `config.ini` 中已設定 WiFi，裝置會：
- 自動連接網路
- 透過 NTP（`pool.ntp.org`）同步時間
- 從 OpenWeatherMap 取得天氣資料

頂部狀態列顯示：WiFi 狀態、電池百分比及充電指示。

## 電子書閱讀器

### 書籍列表

在主畫面點擊**電子書**。書籍列表顯示 `/books/` 中所有的 `.txt` 和 `.epub` 檔案。點擊書名即可開啟。

### 閱讀畫面

書籍以**傳統直排中文排版**顯示 — 文字由上而下排列，分欄由右至左：

```
┌──────────────────────────────┐
│  狀態列                       │
├──────────────────────────────┤
│        │        │        │   │
│  第3欄  │  第2欄  │  第1欄  │   │
│        │        │        │   │
│  ↓     │  ↓     │  ↓     │   │
│        │        │        │   │
│     ←── 閱讀方向             │
│                              │
├──────────────────────────────┤
│  進度：第 5/120 頁  4%       │
├──────────────────────────────┤
│ ◀  ▶  │ 字- 30 字+ 字型 BM │◉│
└──────────────────────────────┘
```

### 閱讀操作

| 區域 | 操作 |
|------|------|
| **螢幕左半部** | 下一頁（向前） |
| **螢幕右半部** | 上一頁（向後） |
| **◀ 左箭頭** | 下一頁 |
| **▶ 右箭頭** | 上一頁 |
| **字-** | 縮小字體（最小 20px） |
| **字+** | 放大字體（最大 64px） |
| **字型** | 開啟字型選擇選單 |
| **BM** | 新增/移除書籤（填滿 = 已加書籤） |
| **◉ 返回** | 回到書籍列表 |

- 字體大小以 4px 為單位調整，跨次使用時自動儲存
- 調整字體大小或切換字型時保持閱讀位置
- 閱讀進度**自動儲存**至書籍旁的 `.pos` 檔案
- 每本書最多 **5 個書籤**，儲存至 `.bm` 檔案

### 字型選擇

字型選單顯示 `/fonts/` 中的所有字型。每個字型以自身字體顯示範例：
- **▣** = 預渲染 BIN 字型（最快渲染）
- **Ⓣ** = TTF/TTC 字型（可重排版，任意大小）
- **✓** = 目前選用的字型

| 操作 | 動作 |

## 天氣面板

需要 WiFi 連線並在 `config.ini` 中設定 OpenWeatherMap API 金鑰。

### 顯示配置

- **城市名稱**及天氣圖標
- **目前溫度**（大字居中）
- **體感溫度**
- **詳細資訊網格：** 最低/最高溫、濕度、風速、氣壓、能見度、日出/日落
- **空氣品質指數 (AQI)：** PM2.5、PM10、O₃、NO₂、CO 含中文品質標籤（優/良/中等/差/極差）
- **三日天氣預報**含溫度及中文描述

### 操作

| 操作 | 動作 |
|------|------|
| **↻ 重新整理**（左下） | 強制更新天氣資料 |
| **°C/°F**（右下） | 切換溫度單位 |
| **返回** | 回到主畫面 |

在天氣畫面時每 15 分鐘自動更新。

## 倉頡輸入法

**倉頡輸入法（倉頡五代）** 螢幕鍵盤用於新增待辦事項和購物清單項目。

### 使用方式

1. 使用螢幕上的 QWERTY 鍵盤輸入倉頡字根碼
2. 每個按鍵對應一個倉頡字根（例如 `a`=日、`b`=月、`c`=金、`d`=木）
3. 符合的候選字顯示在鍵盤上方的列表中（每頁最多 8 個）
4. **點擊候選字**選取
5. 繼續組字
6. 點擊**確定**新增已組成的文字
7. 點擊**取消**捨棄

### 按鍵對應字根表

```
Q手  W田  E水  R口  T廿  Y卜  U山  I戈  O人  P心
 A日  S尸  D木  F火  G土  H竹  J十  K大  L中
  Z重  X難  C金  V女  B月  N弓  M一
```

**特殊按鍵：** `←Del`（退格）、`Space`（空格）、候選字翻頁箭頭（`<` / `>`）

## BLE 近距離解鎖

使用 Paper S3 作為無線鑰匙，自動鎖定和解鎖 Mac。

### 運作原理

1. Paper S3 持續以 **BLE 信標**方式廣播（無需配對）
2. macOS 配套腳本監控藍牙訊號強度 (RSSI)
3. 當您離開 → 訊號下降 → Mac 自動鎖定
4. 當您回來 → 偵測到訊號 → 配套腳本在本機輸入密碼解鎖

### 設定步驟

**步驟 1：在裝置上啟用 BLE**

在 SD 卡的 `config.ini` 中加入 `[unlock]` 區段：

```ini
[unlock]
enabled=true
device_name=M5Paper-BLE
```

| 欄位 | 說明 |
|------|------|
| `enabled` | `true` 開機時啟用 BLE 廣播 |
| `device_name` | BLE 裝置名稱（配套腳本用來搜尋裝置） |

**步驟 2：安裝並執行配套腳本**

```bash
pip install bleak
python3 scripts/ble_unlock.py --password '你的Mac密碼'
```

密碼安全儲存於 **macOS 鑰匙圈** — 不會存於任何設定檔中。之後執行無需再輸入 `--password`：

```bash
python3 scripts/ble_unlock.py
```

**步驟 3（選用）：作為背景服務執行**

```bash
python3 scripts/ble_unlock.py --install-service
```

這會建立 macOS LaunchAgent，登入時自動啟動。密碼從鑰匙圈讀取。

### 設定選項

| 參數 | 預設值 | 說明 |
|------|--------|------|
| `--password` | — | Mac 登入密碼（儲存至 macOS 鑰匙圈） |
| `--name` | `M5Paper-BLE` | 要監控的 BLE 裝置名稱 |
| `--lock-threshold` | `-85` | RSSI 低於此值觸發鎖定 (dBm) |
| `--unlock-threshold` | `-70` | RSSI 高於此值觸發解鎖 (dBm) |
| `--lock-delay` | `15` | 離開多少秒後鎖定 |
| `--scan-interval` | `3` | BLE 掃描間隔秒數 |
| `--debug` | — | 啟用詳細日誌 |

### 安全說明

- Mac 密碼儲存於 **macOS 鑰匙圈**（加密儲存，不會以明文存於任何檔案）
- 無需藍牙配對 — 裝置為被動信標
- 配套腳本在 Mac 本機執行，處理所有鎖定/解鎖邏輯

## 設定

在主畫面點擊**設定**。提供六項設定：

### 1. WiFi 設定

- 掃描可用網路
- 從列表中選擇網路
- 使用螢幕鍵盤輸入密碼（3 種模式：小寫、大寫、符號）
- 下方顯示連線狀態

### 2. 時區設定

- 從 7 種時區預設中選擇（UTC、北京/台北、東京、美西、美東、英國、雪梨）
- 更改後透過 NTP 重新同步時間

### 3. 檔案上傳伺服器（Web Server）

- 開關內建 HTTP 檔案管理器
- 執行時顯示網址（例如 `http://192.168.1.100`）
- 從同一網路的任何瀏覽器存取
- 詳見 [網頁檔案管理器](#網頁檔案管理器)

### 4. USB 外接磁碟（USB Mass Storage）

- 將 SD 卡作為 USB 磁碟暴露給電腦
- **警告：** 啟用期間裝置無法存取 SD 卡
- 啟用 USB MSC 時會自動關閉 WiFi 和網頁伺服器以節省電力
- 停用 USB MSC 會**重新啟動裝置**（重啟後 WiFi 會自動重新連線）

### 5. 圖標來源

- **SD 卡優先** — 從 `/icons/` 載入自訂圖標，找不到時使用內建
- **內建圖標** — 使用內建圖標（開機較快）

### 6. 曆法計算

- **Meeus 天文算法** — 更高精確度（約 1 分鐘精確度）
- **壽星天文曆** — 運算速度較快

## 網頁檔案管理器

啟用網頁伺服器（設定 → 檔案上傳伺服器）後，可透過任何網頁瀏覽器管理 SD 卡檔案。

### 存取方式

1. 在設定中啟用伺服器
2. 記下顯示的網址（例如 `http://192.168.1.100`）
3. 在同一 WiFi 網路的瀏覽器中開啟該網址

### 功能

| 功能 | 說明 |
|------|------|

| **下載** | 從 SD 卡下載檔案 |
| **刪除** | 移除檔案或資料夾 |
| **截圖** | 擷取目前電子墨水螢幕畫面 |

- **💾 儲存** — 下載截圖為 PNG

## USB 大容量儲存

作為網頁檔案管理器的替代方案，用於傳輸檔案。

1. 前往設定 → **USB 外接磁碟**
2. 啟用 USB MSC 模式
3. SD 卡會作為可移除式磁碟出現在電腦上（`Paper SD`）
4. 透過檔案管理員直接複製檔案
5. **完成後請停用 USB MSC** — 這會重新啟動裝置

> **注意：** USB MSC 啟用期間，裝置本身無法存取 SD 卡。WiFi 和網頁伺服器會自動關閉以節省電力。停用 USB MSC 後裝置會重新啟動，所有功能恢復正常。

## 疑難排解

### 裝置無法開機 / 空白畫面

- **檢查 SD 卡：** 取出重新插入。確認為 FAT32 格式。
- **不插 SD 卡試試：** 裝置可在無 SD 卡時開機（功能受限）。
- **重新燒錄韌體：** 連接 USB-C 並執行 `pio run -t upload`。
- **硬重置：** 長按電源按鈕 10 秒以上。

### WiFi 無法連線

- 確認 `config.ini` 中的 SSID 和密碼（區分大小寫）
- 僅支援 2.4 GHz 網路（5 GHz 不會出現）
- 嘗試透過設定 → WiFi 設定使用螢幕鍵盤連線
- 檢查密碼中的特殊字元是否正確

### 天氣不顯示

- 確認 `config.ini` 中的 OpenWeatherMap API 金鑰
- 新的 API 金鑰可能需要最多 2 小時才能啟用
- 檢查 WiFi 連線 — 天氣功能需要網路
- 點擊天氣畫面左下的重新整理按鈕
- 確認城市格式：`城市,國碼`（例如 `Taipei,TW` 或 `Pasadena,CA,US`）

### 書籍未顯示

- 將檔案放入 SD 卡的 `/books/`（不是子資料夾）
- 支援格式：`.txt`（UTF-8）和 `.epub`
- 最多 20 本
- 以 `.` 開頭的檔名會被隱藏（例如 macOS 的 `._` 檔案）

### 電子墨水螢幕殘影

- 這是電子墨水局部更新的正常現象（勾選框切換、彈出視窗互動）
- 切換到其他畫面再切回來即可全螢幕重新整理
- 所有全螢幕重繪使用高品質模式以清除殘影

### 字型渲染不正確

- 確認字型檔為有效的 TTF 或 TTC
- 將字型放入 SD 卡的 `/fonts/`
- 嘗試建議字型：`GenYoMinTW-Regular.ttf`
- 若未載入自訂字型，裝置會使用內建的日文明朝體字型

### 觸控無回應

- 電子墨水螢幕在更新期間有短暫的無回應期 — 請等待更新完成
- 若持續無回應，嘗試硬重置（長按電源按鈕 10 秒以上）
- 觸控感測器（GT911）連接 GPIO 21

### 裝置耗電過快

- 裝置在閒置 10 分鐘後自動休眠
- 不使用天氣或網頁伺服器時請停用 WiFi
- 時鐘畫面會保持裝置喚醒 — 離開以允許自動休眠
- 充電狀態以電池圖標旁的 **+** 符號表示

### SD 卡錯誤 / 資料損壞

- 移除 SD 卡前請務必安全退出
- 實際移除卡片前請先停用 USB MSC 模式
- 使用高品質 microSD 卡（建議 Class 10 或 UHS-I）
- USB MSC 模式期間 WiFi 和網頁伺服器會自動關閉

### 無法連線網頁檔案管理器

- 確認電腦和裝置在同一 WiFi 網路
- 檢查設定 → 檔案上傳伺服器中顯示的 IP 位址
- 嘗試 `http://`（非 `https://`）
- 防火牆軟體可能封鎖通訊埠 80

### 倉頡輸入 — 找不到字元

- 倉頡五代字典需要 SD 卡上的 `/cangjie5.bin`
- 字典中未收錄所有字元 — 嘗試其他碼序列
- 最長碼為 5 個字根
