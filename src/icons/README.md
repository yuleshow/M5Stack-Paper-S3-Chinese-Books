# Embedded Icons

![Generated](https://img.shields.io/badge/Type-Auto--Generated-yellow)
![C++](https://img.shields.io/badge/Language-C++-blue)

Auto-generated C header files containing PNG icon data as PROGMEM byte arrays.

Generated by `scripts/convert_icons.py` from the PNG files in `assets/icons/`.

## Files

| Header | Source | Description |
|--------|--------|-------------|
| `icon1_png.h` – `icon8_png.h` | `assets/icons/icon1.png` – `icon8.png` | Dashboard menu icons (8 total) |
| `back_png.h` | `assets/icons/back.png` | Back / previous page navigation |
| `next_png.h` | `assets/icons/next.png` | Next page navigation |
| `return_png.h` | `assets/icons/return.png` | Return to dashboard navigation |

## Format

Each header defines two constants:
```cpp
const unsigned char icon1_png[] PROGMEM = { ... };
const unsigned int icon1_png_len = ...;
```

These are included via `embedded_icons.h` and used as fallback icons when SD card icons are not available.

## Regeneration

```bash
python3 scripts/convert_icons.py
```
