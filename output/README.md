# Output

![Generated](https://img.shields.io/badge/Type-Auto--Generated-yellow)
![Build Output](https://img.shields.io/badge/Usage-Build_Output-green)

Intermediate build output directory for font conversion. Contains pre-rendered binary font files generated by `scripts/convert_ttf_to_bin.py`.

This directory is gitignored — files here are generated locally and not needed for firmware compilation.

## Files

Typical contents:
- `MingLiU.bin`, `MingLiU_30pt.bin`, `MingLiU_40pt.bin` — MingLiU font at various sizes
- `NotoSerifTC.bin`, `NotoSerifTC_60pt.bin` — Noto Serif TC font variants

These `.bin` files can be copied to the SD card's `fonts/` directory for use as reading fonts.
