# Pre-Rendered Label Bitmaps

Auto-generated C header files containing pre-rendered Chinese text as 4-bit grayscale bitmaps.

Generated by `scripts/convert_labels.py`.

## Purpose

Rendering Chinese text via TTF fonts on an ESP32 is slow, especially on e-ink displays. This system pre-renders all static UI strings at build time into bitmap data that can be drawn instantly — no font loading or glyph rasterization needed at runtime.

## How It Works

1. `scripts/convert_labels.py` reads a list of Chinese strings and their target font sizes
2. Each string is rendered using a TTF font (Pillow/PIL) at the specified size
3. The rendered bitmap is encoded as 4-bit grayscale (matching the e-ink display's 16 gray levels)
4. Each bitmap is written as a C header file with the pixel data as a `PROGMEM` byte array
5. `label_bitmaps.h` is the master header that includes all labels and provides the `findLabelBitmap()` lookup function

## Key File

- **`label_bitmaps.h`** — Master header with:
  - `#include` for all individual label headers
  - `LabelBitmap` struct definition (text, size, width, height, data pointer)
  - `allLabels[]` array of all registered bitmaps
  - `findLabelBitmap(text, size)` — O(n) lookup by text content and font size

## Runtime Usage

```cpp
// In ui_drawing.cpp — drawSystemText():
const LabelBitmap* bmp = findLabelBitmap("設定", 32);
if (bmp) {
    // Draw pre-rendered bitmap — instant
} else {
    // Fall back to TTF rendering — slower
}
```

## Stats

- ~1200 pre-rendered labels
- ~1 MB total bitmap data
- Covers: dashboard titles, menu items, calendar terms (天干/地支/節氣/宜忌), weather labels, status messages, digits, punctuation, and more

## Regeneration

```bash
python3 scripts/convert_labels.py
```
